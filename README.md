# Baby Tracker 👶

Мобильное веб-приложение для отслеживания трёх потребностей новорождённого: **кормление**, **подгузник**, **сон**. Прогнозирует время следующего события на основе среднего интервала между прошлыми записями.

Живая версия: **https://tummlerea.github.io/Baby-Routine/**

## Возможности

- Три большие кнопки одним нажатием: Кормление, Подгузник, Сон/Проснулась (тумблер определяется по последней записи сна).
- Прогноз следующего события по среднему интервалу последних 5 записей. Если данных ещё нет — используется оценка по умолчанию для новорождённого (кормление ~2.5 ч, подгузник ~2 ч, сон ~1.5 ч), с пометкой «оценка».
- Баннер «спит уже …», пока активен сон.
- Журнал всех событий (по убыванию времени) с возможностью удалить ошибочную запись.
- Редактируемое имя малыша.
- Тёмная тема, крупные тач-таргеты — удобно нажимать одной рукой ночью.
- Живые часы в шапке, прогнозы пересчитываются автоматически.

## Технологии

Чистый HTML/CSS/JS, без фреймворков и сборки. Все данные хранятся только в `localStorage` браузера — никакого бэкенда и никакой отправки данных куда-либо.

## Запуск локально

Просто откройте `index.html` в браузере — файл `file://` работает так же, как и на сервере. Никаких `npm install` не требуется.

## Деплой

Раздаётся статикой через GitHub Pages: Settings → Pages → Source: ветка `main`, папка `/ (root)`.

## Хранение данных

- `baby-tracker-events` — JSON-массив событий: `{ id, type: "feed"|"diaper"|"sleep_start"|"sleep_end", time: ISO-8601 }`.
- `baby-tracker-name` — имя малыша (строка).
