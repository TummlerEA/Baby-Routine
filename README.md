# Baby Tracker 👶

Мобильное веб-приложение для отслеживания трёх потребностей новорождённого: **кормление**, **подгузник**, **сон**. Прогнозирует время следующего события на основе типичного интервала между прошлыми записями.

Живая версия: **https://tummlerea.github.io/Baby-Routine/**

## Возможности

- Три большие кнопки одним нажатием: Кормление, Подгузник, Сон/Проснулась (тумблер определяется по состоянию сна).
- **Прогноз** следующего события по медиане последних 5 интервалов. Интервалы короче 10 минут отбрасываются — случайный двойной тап ночью не сбивает предсказание. Если данных ещё нет, используется оценка по умолчанию для новорождённого (кормление ~2.5 ч, подгузник ~2 ч, сон ~1.5 ч) с пометкой «оценка».
- **Баннер активного сна** «спит уже …». Если сон идёт дольше 12 часов, приложение подсказывает, что пробуждение, возможно, забыли отметить.
- **Журнал по дням**: записи сгруппированы по датам, последние два дня раскрыты, старые свёрнуты в заголовки — но всегда доступны одним касанием. В заголовке дня итоги: сколько кормлений, подгузников и сколько всего спали.
- **Длительность сна** считается автоматически по парам «Уснула → Проснулась»; сон через полночь корректно делится между сутками. Непарные записи помечаются предупреждением.
- **Редактирование**: тап по записи в журнале открывает форму с её данными.
- **Добавление задним числом** — для пропущенных или тестовых записей.
- **Удаление с отменой**: после удаления семь секунд доступна кнопка «Отменить».
- **Экспорт и импорт**: CSV (открывается в Excel), Markdown (читаемый отчёт) и JSON (резервная копия). Загрузка из CSV или JSON добавляет записи к существующим, пропуская повторы.
- Редактируемое имя малыша.
- Тёмная тема, крупные тач-таргеты — удобно нажимать одной рукой ночью.
- Живые часы в шапке; экран обновляется сразу при возврате в приложение.

## Технологии

Чистый HTML/CSS/JS, без фреймворков и сборки. Все данные хранятся только в `localStorage` браузера — никакого бэкенда и никакой отправки данных куда-либо.

## Запуск локально

Просто откройте `index.html` в браузере — файл `file://` работает так же, как и на сервере. Никаких `npm install` не требуется.

## Деплой

Раздаётся статикой через GitHub Pages: Settings → Pages → Source: ветка `main`, папка `/ (root)`.

## Хранение данных

- `baby-tracker-events` — JSON-массив событий: `{ id, type: "feed"|"diaper"|"sleep_start"|"sleep_end", time: ISO-8601 }`.
- `baby-tracker-name` — имя малыша (строка).

Данные не покидают браузер и никуда не отправляются. Обратная сторона: они существуют в одном экземпляре — очистка данных сайта или смена телефона их уничтожит. Раздел «Экспорт и импорт» позволяет сохранить резервную копию и восстановиться из неё.
